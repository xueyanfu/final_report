Project-specific modeling
-------------------------
The seven-joint Craig modified-DH table was supplied by the user and is retained
as docs/assets/mdh_user_table.png. It is implemented independently in
experiments/kinematics/rizon4_mdh.py and compared with the MJCF model.
The MDH implementation is not a replacement license or authorship claim for
the upstream MJCF/mesh assets.

All kinematic comparisons use the fixed-base seven-joint model and the world
pose of the link7 BODY origin. This is not an additional tool TCP. The MDH base
transform includes a world-Z translation of 0.365 m. Simulation consistency
with this model is not physical robot calibration or measured hardware accuracy.
