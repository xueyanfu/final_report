# 代码来源与项目改动

本项目以 Flexiv Rizon4 的公开 MJCF 模型为对象，调用 Pinocchio、MuJoCo、SciPy 等开源库，并结合 MDH 参数表构建实验。下文区分参考后改写的代码、直接保留的上游文件、库接口调用和相关研究。DLS、样条、动力学前馈与误差驱动细分均为已有方法；项目贡献按具体实现和实验记录描述。

## 3. 实验14的课程创新边界

原逐点 DLS 优化单个关节构型，使当前目标位姿残差下降。实验14在既有精化五次样条上，优化每个区段的系数，并将区间内多个时刻的位姿残差共同用于 DLS 更新：

\[
\widetilde q_i(s)=q_i^{\mathrm{base}}(s)+\sum_{k=0}^{K-1}b_k(s)c_{ik},\qquad
b_k(s)=64s^3(1-s)^3(2s-1)^k.
\]

由于所有修正基在区段两端都满足 `b=b'=b''=0`，修正不会改变既有 IK 节点的位置、速度和加速度。相应系数 Jacobian 由位姿残差 Jacobian 按链式法则得到：`A=[b0 J, b1 J, …]`。这是相对本项目逐点开源基线的明确算法扩展，核心代码在 `segment_system()` 和 `correct_segments()`。

本方法仍使用已有的 DLS、样条和残差优化思想。没有进行足以确立研究首创性的系统文献审查，不能称为“首次提出轨迹级 IK”“新的 DLS 数学算法”或“优于全部现有轨迹优化方法”。固定节点数也不代表相同算力：四个修正基对应每区段额外 28 个系数，并增加 FK/Jacobian 计算。修正保留 C² 连续性，三阶导数可能在区段边界跳变；采样 jerk 预算不等于连续时间峰值证明。

## 4. 相关研究与实际代码来源的区别

以下资料用于理解研究背景和界定贡献，未作为直接复制的源码输入，也未在本项目中完整复现：

- [Kang 与 Yoon，TORM，Autonomous Robots 2022](https://sglab.kaist.ac.kr/TORM-auro/)：已有将 Jacobian IK 与轨迹优化结合、同时考虑路径误差和平滑性的研究。不能把“考虑整条轨迹”单独当作新思想。
- [Hauser，Fast Interpolation and Time-Optimization on Implicit Contact Submanifolds，RSS 2013](https://motion.cs.illinois.edu/papers/RSS2013_InterpolationOptimizationManifolds.pdf)：已有样条中点投影、切向投影与递归细分研究。本项目不声称实现了该论文算法或继承其理论保证。

实验14的直接代码基础仍是本项目的 `rizon4_ik.py` 和 `smooth_trajectory.py`。上述论文仅为相关研究；README 中应分别标注两类来源。

## 7. 许可与环境

第三方许可证仅适用于对应内容。本项目尚未为项目自有代码另行指定统一开源许可证；“可上传 GitHub”不等于已经赋予所有内容同一许可证，不应自行把整个仓库标成 MIT、BSD 或 Apache-2.0。

Pybotics 3.1.2 声明支持 NumPy `>=1.22,<2.0`。已有实验在 NumPy 2.5.4 环境中仅核对所调用的 FK/Jacobian 接口，不能据此宣称完整兼容。它是实验11的可选交叉检查依赖，不是 Robotics Toolbox。

环境文件用于复现入口，不是已完成跨平台验证的锁文件。具体运行版本以各结果目录元数据为准；历史环境记录与新实验的 MuJoCo 版本可能不同，不能统一改写历史结果的版本号。
